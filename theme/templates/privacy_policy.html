Política de Privacidad de Araya Móvil

Última actualización: 13 de octubre de 2026

Esta Política de Privacidad describe cómo Araya Móvil trata la información utilizada por la aplicación para operar registros productivos, órdenes de trabajo, partes de entrada y vales de consumo asociados al sistema interno de gestión Araya.

1. Responsable del tratamiento

Araya Móvil es una aplicación corporativa operada para usuarios autorizados de Araya Ltda. Para consultas sobre privacidad o uso de datos, los usuarios deben contactar al administrador del sistema o al canal de soporte informado por la empresa.

2. Datos que puede tratar la aplicación

La aplicación puede tratar los siguientes datos, según el uso autorizado del sistema:

  • Credenciales de acceso o token de sesión para autenticar al usuario.
  • Nombre de usuario y último usuario utilizado para facilitar el inicio de sesión.
  • URL del servidor configurado por el usuario o por la organización.
  • Datos operativos de órdenes de trabajo, artículos, cantidades, encargados, fechas y documentos asociados.
  • Registros creados desde la aplicación, incluyendo partes de entrada, vales de consumo y observaciones ingresadas.
  • Datos técnicos mínimos necesarios para sincronizar registros pendientes cuando exista conexión.

3. Finalidad del uso de datos

Los datos se usan exclusivamente para:

  • Autenticar usuarios autorizados.
  • Consultar y registrar información productiva y logística.
  • Sincronizar registros móviles con el servidor corporativo.
  • Mantener trazabilidad operacional de documentos internos.
  • Permitir el funcionamiento offline temporal de registros pendientes de sincronización.

4. Almacenamiento en el dispositivo

La aplicación puede almacenar localmente configuración, token de sesión, último usuario y registros pendientes de sincronización. Esta información se conserva en el dispositivo para permitir el funcionamiento de la app y se transmite al servidor corporativo cuando se sincroniza.

5. Compartición de datos

Araya Móvil no vende datos de usuarios ni los comparte con fines publicitarios. Los datos operativos se envían al servidor corporativo configurado en la aplicación. También pueden intervenir proveedores tecnológicos necesarios para la operación de la infraestructura, alojamiento, seguridad, distribución de la app o servicios de Google Play, siempre limitados a la prestación del servicio.

6. Permisos del dispositivo

La aplicación utiliza conexión a Internet para comunicarse con el servidor configurado. No requiere acceso a ubicación precisa, cámara, micrófono, contactos ni archivos personales para su funcionamiento principal.

7. Seguridad

Se aplican medidas razonables de seguridad para proteger la información, incluyendo autenticación y comunicación con servidores mediante HTTPS cuando el servidor configurado lo soporta. El acceso a la aplicación está limitado a usuarios autorizados.

8. Retención de datos

Los datos se conservan mientras sean necesarios para fines operativos, administrativos, legales o de auditoría. Los registros locales pendientes pueden permanecer en el dispositivo hasta que se sincronicen o sean gestionados por el usuario autorizado.

9. Derechos de los usuarios

Los usuarios pueden solicitar información, corrección o eliminación de datos según corresponda a través del administrador del sistema o del canal interno definido por Araya Ltda. Algunas solicitudes pueden estar sujetas a obligaciones legales, contractuales u operacionales de conservación.

10. Cambios a esta política

Esta política puede actualizarse para reflejar cambios en la aplicación, requisitos legales o prácticas operacionales. La versión vigente estará disponible en esta página.
